# Тест по истории анимации

Next.js 14 (App Router), без базы данных и бэкенда.

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
```

## Продакшен-сборка
```bash
npm run build
npm start
```

## Деплой на Vercel
1. Залейте проект на GitHub.
2. На vercel.com: Add New, Project, выберите репозиторий.
3. Нажмите Deploy (настройки менять не нужно, Next.js определяется сам).
